// C2E
COLLABORATIVE INNOVATION

Every purchase can create more value.

C2E links everyday shopping to small savings customers can track, clear value for shops and brands, and support for community causes that customers choose.

CustomerBuilds savings
RetailerEncourages repeat visits
BrandLearns from missed demand
Explore the complete concept ＋

How it works

  1. Buy an eligible product. Each eligible product has its own single-use code, tied to that unit or batch and to the shop that sells it.
  2. Claim securely. The customer opens the redemption page and enters the scratched code and the phone details they registered. The server then checks that the code is valid and hasn't been used.
  3. Credit once. Once the check passes, the savings are credited. Scanning a QR code on its own never triggers a payment.
  4. Improve availability. When a product is out of stock, Stockout Rescue can point shoppers to nearby shops that have it. Retailer tools can help shops keep track of stock, transfers and their records.
  5. Learn and improve. Combined, privacy-protected data can show which purchases were missed and help decide what to restock or promote.

Three connected parts

A customer web page, a mobile app for small shops and a PC app for larger stores. All three connect to one shared server that keeps separate records for customers, shops and the project.

Features we might add

Savings Passport • Stockout Rescue Network • Retailer Reliability Dividend • Smart Boost • Intelligent Restock • Family Circle • Offline Access • Community Allocation.

How we'd start

Start small with a pilot we can measure: secure code redemption, a savings record and a few shops taking part. Before adding the stockout and other advanced features, test whether the numbers work, whether customers use it, how much fraud shows up and how it runs day to day for shops.

C2E is an early idea, not a live service. There are no partnerships, results or regulatory approval yet, and it hasn't been shown to be financially workable.
